# تحليل معدل ترك العملاء (Churn Analysis)

## نظرة عامة على المشروع
يهدف هذا المشروع إلى تحليل ظاهرة ترك العملاء (Churn) في إحدى شركات الاتصالات، وذلك لتحديد فئات العملاء التي تسجل معدلات ترك مرتفعة وتقديم توصيات مبنية على البيانات لتعزيز الاحتفاظ بالعملاء.

## الأدوات المستخدمة
- SQL Server
- Power BI
- Power Query
- DAX

## مجموعة البيانات
تتضمن مجموعة البيانات 7,043 سجلاً للعملاء، وتشمل تفاصيل العقود، وخدمات الإنترنت، وطرق الدفع، والرسوم الشهرية، ومدة الاشتراك (فترة البقاء)، وحالة العميل (مستمر أو مغادر).

## النتائج الرئيسية
- معدل ترك العملاء الإجمالي: **26.54%** (1,869 عميلاً).
- تسجل العقود الشهرية المتجددة (شهر بشهر) أعلى معدل ترك بنسبة **42.71%**.
- يبلغ معدل ترك عملاء خدمة الألياف الضوئية (Fiber optic) **41.89%**.
- يبلغ معدل ترك مستخدمي الدفع عبر الشيكات الإلكترونية **45.29%**.
- يبلغ متوسط ​​الرسوم الشهرية للعملاء المغادرين (**74.44**) أعلى منه لدى العملاء المستمرين (**61.27**).
- يبلغ متوسط ​​فترة الاشتراك للعملاء المغادرين (**17.98 شهراً**) أقل منه لدى العملاء المستمرين (**37.57 شهراً**).

## التوصيات
- تشجيع العملاء المشتركين بنظام العقود الشهرية على النظر في خيارات العقود طويلة الأجل.
- دراسة جودة الخدمة، والأسعار، وتجربة العميل لدى مستخدمي خدمة الألياف الضوئية.
- مراجعة تجربة الدفع للعملاء الذين يستخدمون الشيكات الإلكترونية.
- تقييم عروض الاحتفاظ بالعملاء الذين يتحملون رسوماً شهرية مرتفعة.
- تعزيز عمليات تهيئة العملاء الجدد (Onboarding) ومستويات التفاعل المبكر معهم.

## مخرجات المشروع
تم إنشاء لوحة معلومات (Dashboard) باستخدام Power BI لمراقبة مؤشرات الأداء الرئيسية (KPIs) المتعلقة بترك العملاء، ومقارنة فئات العملاء، ودعم اتخاذ القرارات الخاصة بالاحتفاظ بهم.
